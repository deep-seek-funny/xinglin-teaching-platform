# 数据契约与评分口径（脱敏版）

## 一、档案结构

每名学生一份档案，包含身份信息与各模块记录：

```
档案 = {
  身份: 编号、名称、班级、是否游客、角色（对外需匿名）,
  问诊记录[], 提示词评估记录[], 核型记录[], 会诊记录[], 自检记录[],
  图谱状态 { 病例 → 探索/建造/评分台账 },
  人体图谱作业 { 逐结构条目, 累计分, 版本 },
  思政雷达 { 四维分, 依据, 评语 }
}
```

- 存储：历史全量数组 + 每生一个独立文件；独立文件覆盖历史行，删除用"墓碑"。
- 写入保护：目录锁 + 逐字段比对 + 版本号/请求号，冲突拒绝并提示刷新。
- 证据日志：按天追加的 JSONL，保存模型原始返回、耗时与输入摘要，用于复核；不参与排名。

## 二、各模块记录要点

| 记录 | 必含要点 | 备注 |
|---|---|---|
| 问诊 | 编号、病例、模式、分数(0–100)、日期、轮次、时长、转录、频道、综合评语、四维分 | 转录保留双方原话；频道区分文本/思考语音/实时 |
| 提示词评估 | 编号、病例、百分制分数、日期、提示词原文、写作分(0–50)、执行分(0–60) | 只有一项时按 50 分制归一 |
| 核型 | 编号、时长、罚时、错误、卡点、分轮结果、评语 | **无分值字段** |
| 会诊 | 会话号、输入哈希、分数、六维分、诊断是否正确、模式、评语、转录、医嘱 | 幂等键是输入哈希 |
| 自检 | 编号、模式、日期、总题数、正确数、百分制分数、耗时、节点正确率、逐题结果 | 保留最近数十条 |
| 图谱状态 | 已完成节点、自建节点/边、节点挑战、求助、建造台账、版本 | 探索与建造分开存 |
| 人体图谱 | 逐结构条目（分数、奖项、修改、参考）、累计分 | 累计分是替换式 |
| 思政雷达 | 四维分、引用依据、评语、评了几场 | 模型按对话评分 |

## 三、分数归一化

- 问诊：四视角加权（40/25/25/10）+ 综合评语，总分 0–100；只有全双工模式进排行榜。
- 提示词评估：
  - 只有写作：`写作/50×100`；
  - 写作 + 执行：`((写作/50)+(执行/60))/2×100`。
- 自检图谱：前端按答对题数与节点权重给 0–100。
- 图谱建造：`增量 = round(基础分 × 结构系数 × 质量系数)`，累加进总分；**无上限，不是百分制**。
- 人体图谱：结构分 = 临床×2 + 机制×3 + 证据×1（去重、引用需可匹配），总分 = 各结构分之和（替换式）。
- MDT：六维加权 30/20/20/15/10/5，再套事实限分。
- 核型 AI：总数 30 + 性染色体 15 + 核型式 45 + 结论 10。

**总评不在服务端**：期末计分规则（各项权重、图谱/人体分换算、参与门槛）写在课程文档里，做报表必须引用该文档。

## 四、排名与查重

- 排名服务使用内存快照（启动预热、短间隔兜底重建、最小重建间隔），教师可强制刷新。
- 教师端档案列表是**瘦身视图**（图谱只留编号、剔除作业明细）；完整数据按需单独拉取。
- 同稿归零（提示词评估）：完全同稿按最早提交归属；长文本用双阈值判高度相似；只有首交人是他人时清零，本人旧稿保留。
- 提交查重：短文本片段相似度高且自己非首交人 → 拒绝并记录，不调模型不计数。
- 大屏口径：训练总人次包含各类记录；迭代轨迹中"考试型"模块取历史最好、"累计型"模块取累计值。演示数据开关必须显式标注。

## 五、导出与治理

- 学生汇总与训练明细两类导出：明细按模块取分，**核型无分 → 空/0**，这是已知口径缺陷。
- 账单导入：覆盖账单文件前先备份；大屏区分"平台运行"与"开发调试"两类消耗；账单按日滞后，展示要标日期范围。
- 备份：启动快照 + 手动快照；自动保留策略当前有缺陷（见已知问题）。
- 隐私：档案含对话原文、录音、声纹；对外导出与演示需匿名化（姓名、编号、班级、音频）。

## 六、复刻时的最小数据层

1. 一张"谁/何时/第几次/原文/评分/版本"齐全的证据表（文件亦可，但要有原子写与冲突检测）。
2. 每个模块只写自己的记录类型，聚合查询另做，模块间不互改字段。
3. 原始日志（JSONL）与结构化档案分开：前者复核，后者展示。
4. 所有分数写入前做范围校验；来自客户端的分数必须服务端重算或标记"未校验"。
5. 演示数据必须有显式开关与标记，不能混入真实统计。
