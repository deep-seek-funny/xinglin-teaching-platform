# 图谱与图谱类作业（脱敏版）

## 一、主动知识图谱：探索 + 建造

### 状态与限制

- 学生状态按病例保存：已完成节点、学生自建节点与边、节点挑战记录、AI 求助记录、建造评分台账。
- 节点字段含编号、名称、说明、关键词、分类、坐标与前置关系；边含起止、关系类型与备注。
- 保存上限：节点约 120、边约 360、完成项约 240；超出拒绝保存。
- 并发：带版本号/请求号，冲突时返回"请刷新后重试"；探索完成度达阈值触发一次性奖励（幂等）。

### 探索模式

- 学生沿教师配置的节点与关联追问、求助、挑战；完成后计入探索进度。
- **节点挑战**：全对时走规则判定，**0 次模型调用、不占额度**；否则由模型给出等级、总结、优点、改进与下一步，写回节点评价记录。
- **AI 导师**：检索当前节点、图谱节点与教师知识库，苏格拉底式提问，默认不给答案；学生问题入库用于班级洞察。
- **班级洞察**：聚合探索/答题/求助/建造结构/孤立节点/关系覆盖，生成匿名班级反馈并缓存。

### 建造模式（核心）

- 学生从**空白**开始建自己的图，不是修补教师的图。
- 每次评分流程：
  1. 对作品做归一化与去重（按内容哈希），得到"待评条目"与作品指纹；
  2. **0 调用条件**：没有未评过的新条目 / 新节点全孤立 / 全部已评 → 直接返回"未变化"，不调模型、不加分；
  3. 模型给出奖项、质量分与评语；
  4. 基础分：概念 +2、细节 +1、机制 +2、关系 +2；逐条校验条目存在、类型合法、证据能在原文近似匹配（小幅容错），孤立节点不计分，同类重复去重；
  5. **结算分 = round(基础分 × K × Q)**：
     - `K`（结构系数）= 0.7 + 0.6 × min(边数/连通节点数 ÷ 1.5, 1)，上限 1.3
     - `Q`（质量系数）= 模型 1–5 分时 `0.7 + 0.15×(分-1)`；缺失时用本地启发式（关系类型多样性 + 节点内容充实度 + 最大连通分量覆盖），封顶 1.15
  6. 记账：已认可条目永久记录（含后来被删除的内容）、已评指纹、每轮历史（增量/基础分/K/Q/结构/摘要）、完成度分类计数；
  7. **总分无上限**，是"持续建构积分"，不是百分制能力分；评分期间作品变化则拒绝写入。
- 排行榜按建造总分聚合，排除教师与游客。

### 教师侧

- 图谱配置：节点、附加边、关系的上限与总大小限制；助手配置中接口相关字段仅超级管理员可改。
- 班级评语：AI 批量生成四维评语；可撤销孤立节点的历史分。

## 二、自检图谱：24 题分层测验

- 主测 24 题、5 个阶段（基础识别 / 核型与遗传 / 方法对应 / 临床决策 / 综合），知识点为 K1–K8 加综合题。
- 前端本地判分，服务端只负责：
  - 保存作答（节点正确率、用时、逐题结果），保留最近若干条；
  - **错因分析**：逐题对错 + 节点正确率 + 用时 → 总结、时间洞察、节点建议、行动项；
  - **AI 学伴**：围绕当前题目做启发式引导；
  - **复习规划**：三路并行（前段总览 / 中段节点 / 尾段练习与拓展）合并成路径；只有前段失败才整体失败，中后段失败会少节点但仍返回。
- 与个性化路径的关系：诊断错点 + 讨论误区 + 测验薄弱 → 映射回课程图谱节点 → 生成复习路径。
- 注意：部分综合题在服务端没有名称映射，展示时会显示原始编号。

## 三、人体图谱作业

- 目录化结构：区域 → 结构 → 概念（千级部件、数千概念），学生按结构完成标注。
- 每次提交带"修改内容/参考资料"（各设字数上限）、内容指纹与基准版本号，冲突拒绝。
- 评分流程：
  - 评分期间加锁，作品版本变化则拒绝；失败保留原分；
  - 每个结构分别评分，条目按临床 +2 / 机制 +3 / 证据 +1 计分，每结构证据条数上限 3；
  - 跨结构按"事实键"与来源去重；引用必须能在原文匹配，否则丢弃；
  - **结构得分 = 分项和；总分 = Σ 各结构得分（每次重评替换旧分，不是累加）**。
- 教师可逐人逐结构清零重评（带进度与失败列表）；另有独立榜单。

## 四、改动检查点

- 图谱：先分清"教师配置"与"学生状态"，两者存储与权限不同；改建造评分要重跑文档中的示例，确认 K/Q 与去重行为未变。
- 自检：题目与节点映射在前端，改题要同步节点统计口径与复习路径映射。
- 人体图谱：总分是替换式，重评会让总分下降，前端解释文案需一致。
