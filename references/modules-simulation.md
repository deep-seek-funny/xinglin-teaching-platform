# 对话训练与提示词评估（脱敏版）

## 一、模拟问诊：两种模式，两条技术链

### 思考模式

`录音 → 语音识别 → 文本模型生成患者回复 → 语音合成 → 播放`，逐句推进。

- 服务端把病例事实、教学重点、教师知识材料注入系统提示，并附带轮次进度（默认 15–25 轮，病例可覆盖）。
- 模型回复会清掉自带的情绪/动作标注；达到轮次上限由服务端补"问诊结束"提示。
- 语音链路：识别、回答、合成三步；学生纯净提问音频累计到一定量自动注册声纹，用于后续"AI 代答"检测。
- 清单辅助：只提交"问诊清单 + 最近几轮对话 + 已完成项"，超时短、token 少；失败不阻断训练，由前端关键词兜底。

### 实时模式（全双工）

浏览器与实时语音服务保持长连接，服务端先校验令牌与课程成员，再转发音频与事件。

- 建立会话时注入病例约束、进度、学生锁定提示与固定音色。
- 每累计数秒抽样学生音频，与"患者音色/AI 音色"比对；连续命中记违规，评分时整场 0 分。
- 评分不走实时连接：前端把整场转录交给评分接口。

### 评分：四视角 + 一次综合

- **四个独立评委并行**，各自看到病例 + 对话 + 教师评分表：专业医师 40%、敏感型患者 25%、坚强型患者 25%、学生评委 10%。
- 每位评委自报总分与逐题分，服务端按量规上限截断并保留"量规小计"供核对。
- **第五次调用**只把四分意见合成一段评语，**不允许改分**。
- AI 代答违规：四个评委全部 0 分，跳过综合评语。
- 服务端只写证据日志；档案里的问诊记录由前端另行保存（见数据文档）。
- 训练模式有配额（按病例配置）；档案用字段区分文本/思考语音/实时语音；**排行榜只统计全双工**（按最高分聚合）。

### 档案里的问诊记录

```
{ 编号, 病例, 模式, 分数(0-100), 日期, 轮次, 时长,
  转录[学生/患者发言≤60条], 频道, 综合评语,
  四维评分{病史采集, 临床思维, 沟通共情, 安全计划} }
```

- 录音单独存储，一条记录一份音频，学生只能取自己的文件；在线席位有容量上限与排队。

## 二、提示词评估：写作 50 分 + 执行 60 分

- **写作评价**：10 个维度 × 5 分（清晰度、场景、目标、流程、交互规则、问题引导、身份切换、输出格式、评分标准、防御兜底）。
- **执行评价**：12 道对抗性压力题在独立会话中运行同一份提示词，再从 6 个维度 × 10 分评分（约束防御、角色沉浸、任务引导、对话容错、强制终结与切换、评价学生）。
- 归一化：只有写作 `写作/50×100`；两项都有 `((写作/50)+(执行/60))/2×100`。
- 配额与请求次数：一次完整评估约 14 次模型调用（1 次写作 + 12 次压测 + 1 次总结）；按次计费与限额，额度不足时明确提示。
- 查重：
  - **跨人同稿**：短文本按 5 字片段相似度、阈值 0.85；命中且自己不是首交人 → 拒绝并记录，不调模型不计数。
  - **排行榜同稿归零**：完全同稿按最早提交归属；长文本用双阈值判断高度相似；只有首交人是他人时清零。
- 档案记录：编号、病例、百分制分数、日期、提示词原文、写作分、执行分、来源。

## 三、思政雷达（行为观察）

- 取最近若干场问诊的学生原话，按 **4 个维度 0–100** 评分：生命至上 / 人文关怀 / 职业操守 / 责任担当，并给每个维度的引用依据。
- 结果缓存进档案，按问诊条数与最近日期失效。
- 定位：**表达质量观察**，不是能力测量，也不是品德评价。

## 四、膳食作业（另一种作业链路）

- 草稿 → 附件上传 → 提交 → 教师概览；量规版本化，多次尝试取最佳。
- 与对话类模块的区别：它是"提交 + 量规评分"，不产生对话与语音。

## 五、改动检查点

- 改评分：同时核对病例量规、角色权重、截断/归一化、证据日志字段、前端展示、排行榜口径。
- 改语音：分别验证思考模式、实时模式、违规检测与失败降级；不要只测文本。
- 改配额：内存计数重启清零，前后端提示需一致。
