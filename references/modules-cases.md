# 会诊 / PBL / 核型 / 实验 / 游戏（脱敏版）

## 一、MDT 会诊：有状态任务

- 形态：同源子应用，逐步解锁的会诊流程；对话、草稿保存、交卷评分三类操作。
- **状态机**：家长问诊 → 体格检查 → 病历核查（含埋错，必须纠正）→ 检查回报（有先后前提）→ 多学科会诊（≥3 科室意见）→ 诊断（ICD）→ 遗传咨询 → 反思 → 会诊记录（各环节有最少字数）。
- 评分：**6 个维度，权重 30/20/20/15/10/5**（线索诊断 / 检查决策 / 遗传学 / 多科整合 / 沟通伦理 / 反思与 AI 核查）。
- **确定性事实限分**（在模型分之上再套规则）：检查时序错误 → 检查决策维封顶；诊断错误 → 诊断与遗传学维封顶；病历纠错比例低 → 反思维封顶；总分截断 0–100。
- 解锁自由模式：引导模式完成 + 提交齐全 + 正式评分达标 + 诊断 ICD 正确 + 埋错全部纠正。
- 幂等：按"评分输入哈希"去重，重复提交返回既有成绩；会话级锁防并发。
- 记录：会话号、输入哈希、病例、版本、分数、六维分、诊断是否正确、模式、埋错纠正数、评语、转录、医嘱、会诊过程、最终文书、日期。

## 二、PBL 讨论：独立服务

- 部署形态：主应用只做反向代理，PBL 是独立进程与独立数据目录。
- 主应用的两个接入点：
  - **学生个人小结**：直接读取 PBL 落盘的评价与路径文件，按本人学号过滤；无数据时返回演示数据（需显式标记），并补齐知识图谱映射；
  - **教师汇总**：调用 PBL 自己的汇总接口，短时缓存，失败返回"不可用"。
- **只读边界**：主应用不回写 PBL 数据。
- PBL 内部能力（独立仓）：讨论录音采集、逐句转录、说话人归属（独立声纹服务）、四轴评价（参与/深度/准确/协作）、个人小结、知识节点映射、自检入口、联合复习路径。
- 风险提示：反代先于鉴权挂载且无请求体/超时限制；上游对本机放行教师门，可能被绕过（见已知问题）。

## 三、手工核型训练

- 形态：同源子应用；教师选择开放轮次，学生按轮完成。
- 交互：拖拽配对 → 判断数目/性染色体/规范表达 → 提交；记录耗时、错误与罚时（每次错误加时）。
- 评分：提交后由模型给出分轮点评与整体总结；模型 JSON 失败时退化为纯文本评语。
- 记录：时长、罚时、错误、卡点、分轮结果、评语、日期——**没有分值字段**，因此导出/大屏/轨迹中核型分恒为 0，榜单按用时聚合，与其他模块口径不同。
- 双人合作：候选、绑定、确认、解绑一组操作；已确认搭档时双方各写一份记录（带共享标记）。
- 文案漂移：页面、壳卡片、README 对"轮数"的说法不一致，以代码的 12 轮为准。

## 四、核型 AI（半接线）

- 形态：同源子应用，代码存在但入口卡片仍是"敬请期待"。
- 流程：学生先独立判断 → 服务端图像检测（两阶段）→ 返回检测与核型推导 → 学生复核。
- 评分：**100 = 总数 30 + 性染色体 15 + 核型式 45 + 结论 10**；总数差 1 得部分分、差 2 得少量分；AI 点评另调模型。
- 记录写独立文件（有上限），**不进主档案、不进排行榜**——典型的"功能已实现但未开放"。

## 六、肿瘤演化游戏（纯前端）

- 玩法：人生轨迹（出生地/迁居/职业/烟酒/饮食等暴露）与天赋树（增殖/死亡/免疫/代谢等机制）在同一局推进；逐月更新风险压力、炎症、微环境、免疫、增殖、死亡，推动克隆分叉与治疗选择；新天赋只影响当时末端克隆，后代继承亲代。
- 技术：规则引擎 + 种子随机；引导模式固定阶段，自由模式保留随机轨迹；模型只润色已发生月份的叙事，不改结局。
- 数据：全部在本地存储，**没有平台记录与统一百分制**，不适合直接作为能力证据。

## 七、知识星云（演示级可视化）

- 三种形态：球形态（球形粒子云）、星空态（星座连线）、神经网络态；数据来自课程图谱层级（章节 → 知识点）。
- 交互：拖动旋转、滚轮缩放、章节聚合、手势控制（摄像头）、点击节点查看详情。
- 定位：课堂大屏/演示，不是训练与评价模块，无数据落点。

## 八、同类小站点（可作复刻参考）

- 另有一个完全独立的小型站点：单文件后端 + 前端，零第三方依赖，托管为系统服务并挂在子路径。
- 能力：对话训练、报告解读、焦虑快筛、短视频/工作流评估、沟通辅助；配置中无模型密钥时自动降级为规则演示。
- 价值：展示"配置化 + 证据落盘 + 降级运行"的最小实现，适合作为复刻起点。

## 九、改动检查点

- MDT：改流程要同时改状态机、提交完整性校验、事实限分、解锁条件，否则会出现"能交卷但永远不解锁"。
- PBL：主应用只读，改结构要同步独立服务；不要把主应用写回当持久化。
- 核型：若要接入大屏/榜单，先设计分值口径，再改导出、轨迹、大屏。
- 游戏/星云/形态：演示可以，对外必须标注"演示/无平台记录"。
