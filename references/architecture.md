# 架构总览（脱敏版）

## 1. 运行形态

- 单体 Node 服务，服务端渲染的静态页面 + 同源 iframe 子应用；无前端构建步骤。
- 单进程运行，数据用 JSON 文件持久化；**不要以多实例方式部署**（写入无跨进程锁）。
- 长任务（模型评估）有较长的请求超时；短请求与长请求共用进程，注意内存。

## 2. 请求链（自上而下）

1. 反向代理（PBL 等独立服务在此转发）
2. 请求体解析（音频接口单独放宽上限）
3. 安全响应头（禁止 MIME 嗅探、限制被嵌入）
4. 登录限流（按 IP，内存计数）
5. 文本资源压缩（整包缓冲，大响应注意内存）
6. 课程运行时：登录/登出/课程/身份接口 + 全局鉴权与课程校验
7. 名单、首页分流、静态资源门禁
8. 各业务模块路由

**改动提示**：鉴权在中间件链的后段，任何挂载更早的路由都会绕过它——这是本平台已出现过的问题（见已知问题）。

## 3. 身份与权限

- 令牌：载荷（身份、角色、课程、过期时间）+ HMAC 签名；有效期约半天；通过请求头或登录种下的 cookie 传递。
- **无会话表、无吊销**：登出只清 cookie，改密不失效旧令牌；签名密钥泄露即可伪造身份。
- 角色：访客 → 学生 → 教师 → 管理员；"超级管理员"是标志位而非独立角色。
- 教师身份每次请求回查教师名单（编号 + 名称双匹配），名单改动可即时生效。
- 课程维度：请求携带课程上下文，默认一门主课；可扩展多课程，课程级配置与全局配置分离（共享字段仍写全局）。
- 限流：业务接口按"课程+角色+身份+类别+日期"内存计数，重启清零。

## 4. 静态资源与门禁

- 少量资源公开（登录页依赖的样式/脚本、部分素材目录）。
- 教学子应用需要登录且属于当前课程才可访问；其余走统一门禁。
- 静态服务整体暴露应用根目录：**不要在根目录放密钥、备份或隐私数据**（已知风险）。

## 5. 数据层

- 结构化档案：一份历史全量数组 + 每生一个独立文件；读取时独立文件覆盖历史行，删除用"墓碑"而非物理删除。
- 写入：临时文件 + 重命名（同卷原子），但**无 fsync、无跨进程锁**；部分写入路径是裸写（见已知问题）。
- 并发控制：快照 + 逐字段比对 + 版本号/请求号，冲突时拒绝写入并提示"档案已被更新"。
- 删除学生：先写日志再执行，启动时幂等恢复，失败可重试。
- 备份：启动快照 + 手动快照；自动保留策略存在缺陷（见已知问题）。
- 证据日志：按天追加的 JSONL，记录模型原始返回、耗时与输入摘要，用于复核；不参与排名。

## 6. AI 能力层

| 能力 | 用途 | 备注 |
|---|---|---|
| 文本模型（DeepSeek，默认） | 对话、评分、评语、规划 | OpenAI 兼容；JSON 模式按需；参数见 [model-apis.md](model-apis.md) |
| 文本模型（豆包方舟，可替换） | 同上 | 同协议，model 填方舟接入点 ID |
| 语音识别/合成（豆包） | 问诊思考模式 | OpenSpeech v3；与实时语音共用语音 Key，参数见 [model-apis.md](model-apis.md) |
| 全双工语音（豆包） | 实时问诊 | WebSocket 事件协议，服务端注入病例约束，音频双向透传 |
| 图像检测 | 核型识别 | 依赖可选运行时，缺失时该模块路由整体跳过 |
| 用量计量 | Token / 请求 / 费用 | 区分"平台运行"与"开发调试"两类消耗 |

**配置现状**：模型名在服务启动时被硬编码覆盖，配置项不生效；多模型 fallback 实际是同一模型重试（见已知问题）。

## 7. 前端形态

- 单文件外壳：样式、视图模板与脚本内联，视图切换函数统一做课程/角色门禁。
- 统一请求封装携带令牌与课程上下文，接口用相对路径（兼容子路径部署）。
- 档案缓存：学生只取自己，教师进入相关视图时按需全量拉取；学生端定时刷新。
- 子应用 iframe 懒加载（进入时赋地址，离开卸载）；模块间用消息桥通信（部分未校验来源，见已知问题）。
- 演示数据开关存在且与真实数据共用界面，展示时需显式标注。
